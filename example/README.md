# NestJS A2A Example

This directory contains example implementations demonstrating how to use the `nestjs-a2a` package.

## Overview

The examples showcase different use cases and configurations of the NestJS A2A module, providing practical implementations that you can reference for your own projects.

## Getting Started

1. Navigate to the example directory:

```bash
cd example
```

2. Install dependencies:

```bash
pnpm install
```

3. Start the example server:

```bash
pnpm start:dev
```

## Testing

To run the example tests:

```bash
pnpm test
```

## Notes

- These examples are meant to be educational and should be adapted to your specific use case
- Make sure to review the configuration options before running the examples
- The examples use mock data and simplified scenarios for demonstration purposes
