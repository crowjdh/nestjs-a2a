# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2024-07-10

### Added

- Initial release of the nestjs-a2a library
- Complete implementation of Google's Agent-to-Agent (A2A) protocol
- `AgentToAgentModule` for easy integration with NestJS applications
- `@Skill` decorator for defining agent skills
- Support for streaming responses
- JSON-RPC 2.0 compliant API
- Built-in task state management with `InMemoryTaskStore`
- Type definitions for A2A protocol components
- Example implementation in the `example` directory
- Comprehensive documentation in README.md
